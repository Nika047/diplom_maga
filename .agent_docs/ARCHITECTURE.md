# Архитектура

**Статус на 18.10.2026: кода нет, ниже - планируемая структура.** При реализации
сверить с кодом и убрать пометку «план».

## Поток данных

```text
логи CSV (read-only) --> чтение и очистка --> истинные траектории (ENU, метки участков)
генератор           --------------------> истинные траектории (только train + синт. анализ)
                                                |
                                     модель РЛС (шум, период, пропуски)
                                                |
                                         отметки РЛС
                                                |
                         CV / KF / IMM  --> прогноз IMM на 1..H обзоров
                                                |
                       окна (причинные) --> корректор (LSTM/GRU/Transformer/Mamba)
                                                |
                         прогноз = IMM + поправка --> метрики, рисунки, отчёт
```

## Модули (план)

| Модуль | Ответственность |
|---|---|
| `config.py` | Все параметры: пределы скоростей, модель РЛС, пороги участков, разбиение, seed |
| `common/` | Настройка журнала (консоль + `log/`), seed, пути |
| `data/` | Чтение логов, очистка, разметка участков, генератор, разбиение, нарезка окон |
| `radar/` | Модель измерений РЛС |
| `filters/` | CV-экстраполяция, фильтр Калмана, IMM |
| `models/` | Корректоры и сквозные модели |
| `training/` | Набор данных, обучение, ранняя остановка |
| `tuning/` | Генетический подбор (Optuna, NSGA-II) |
| `eval/` | Метрики, динамическая ошибка, сводка PASS / FAIL |
| `viz/` | PNG-рисунки и HTML-карта |
| `run_stage0.py` ... `run_stage7.py` | Точки входа этапов |
| `predict.py` | Итоговая программа |

## Соответствие имён

Таблица держится в актуальном виде: путаница имён - частый источник ошибок.

| Сущность | В тексте диплома | В коде (план) | В логе CSV |
|---|---|---|---|
| Файл лога | полёт | `log_file` | имя файла |
| Кусок полёта после разрезания по паузам | полёт (единица разбиения) | `flight_id` = `<имя файла>#<номер куска>` | - |
| Истинная траектория | истинная траектория | `truth`: `t, x, y, z` | `Date`, `Time`, `GPS`, `Alt(m)` |
| Тип участка | прямая / вход / маневр / выход | `phase`: `straight`, `entry`, `turn`, `exit` | - |
| Отметка РЛС | отметка | `meas`: `t, r, az, el` и `meas_xyz` | - |
| Обзор (такт) | обзор | `scan`, индекс `k` | - |
| Горизонт | h обзоров | `horizon` в обзорах, секунды = `horizon * SCAN_PERIOD` | - |
| Тип аппарата | тип БПЛА | `aircraft` | префикс имени файла |
| Режим полёта | режим | `flight_mode` | `FM` |
| Путевая скорость | скорость | м/с | `GSpd(kmh)` - **км/ч** |

## Системы координат и соглашения

- **ENU:** `x` - восток, `y` - север, `z` - вверх, в метрах. Начало координат - в
  точке старта каждого полёта, а не одна общая точка.
- **Курс** в логе (`Hdg(°)`) отсчитывается от севера по часовой стрелке.
  Математический угол `atan2(y, x)` - от востока против часовой. В коде курс
  хранить как в логе: `atan2(vx, vy)`. Внутри фильтров угол не нужен - работать
  с компонентами скорости.
- **Азимут РЛС** - от севера по часовой, как курс.
- **Время:** секунды от начала куска полёта. В старом проекте колонка `dt`
  хранила абсолютное время - здесь так не называть.
