# План ВКР и реализации

Тема (не меняется): «Разработка программы прогнозирования положения воздушного
объекта при помощи алгоритмов экстраполяции на основе нейронной сети».

Номера источников [N] - по `../../литература.md`.

## 1. Цель и задачи

**Объект.** Траектории малоразмерных самолётных БПЛА, наблюдаемых обзорной РЛС.

**Предмет.** Гибридные алгоритмы экстраполяции «многомодельный фильтр IMM +
нейросетевой корректор».

**Цель.** Разработать программу прогнозирования положения малоразмерного БПЛА по
радиолокационным измерениям на основе гибрида «IMM + нейросетевой корректор».
Гибрид должен уменьшать динамическую ошибку экстраполяции при маневрах.
Архитектуру корректора выбрать по результатам сравнения LSTM, GRU, Transformer и
Mamba.

**Задачи:**
1. Проанализировать методы траекторной обработки и нейросетевого прогноза,
   причины динамической ошибки IMM.
2. Подготовить данные:
   - очистить и разметить логи полётов;
   - построить генератор маневрирующих траекторий;
   - построить модель измерений РЛС.
3. Реализовать базовые методы: линейная экстраполяция, фильтр Калмана, IMM.
4. Реализовать корректор в четырёх архитектурах и сквозные нейросетевые модели
   для сравнения.
5. Подобрать гиперпараметры генетическим алгоритмом с одинаковым бюджетом для
   всех архитектур.
6. Сравнить методы по точности и по динамической ошибке на маневрах. Проверить
   обобщение на тип БПЛА, которого не было в обучении.
7. Добавить прогноз начала маневра (если хватит времени).
8. Разработать программу прогноза и описать её.

## 2. Решаемые проблемы (актуальность)

Тезисы - по источникам, без цитат.

1. **Динамическая ошибка IMM при маневре.**
   - Смена модели занимает несколько тактов, прогноз в это время отстаёт.
   - Если параметры маневра не совпадают с заложенными в модель, смещение
     накапливается весь маневр.
   - После окончания маневра IMM сходится медленно.
   - Источники: [82], [60], [70], [69], [1].
2. **Ограничения чисто нейросетевых методов.** Им нужно много данных, они хуже
   обобщаются вне обучающей выборки и плохо интерпретируются. На реальном радаре
   KalmanNet уступил IMM. Источники: [69], [60], [8], [9].
3. **Вычислительная сложность Transformer.** Сложность растёт квадратично с длиной
   последовательности, у Mamba - линейно. Источники: [41], [69].
4. **Малые БПЛА - нестандартная платформа.** Классические модели движения для них
   ограничены. Задача актуальна для противодействия БПЛА. Источники: [18], [2], [50].
5. **Условия, в которых проверялись прежние работы.** В основном ADS-B авиалайнеров
   или моделирование. Проверок на реальных полётах малых БПЛА с моделью РЛС мало.
   Источники: [1], [69], [61], [60].
6. **Сложная модель не гарантирует выигрыша.** Нужен одинаковый для всех методов
   протокол сравнения с сильными классическими методами. Источники: [20], [35].
7. **Ручной подбор гиперпараметров.** Генетический алгоритм применялся и для
   нейросетей, и для настройки IMM. Источники: [76], [75].

**Относительная новизна** (поиск на 18.10.2026, разделы 11-12 `литература.md`):
- Mamba в роли корректора в гибриде с IMM. В MambaMTT [69] Mamba используется без
  IMM, как сквозная модель.
- Сравнение корректоров LSTM / GRU / Transformer / Mamba на радиолокационных
  трассах малых самолётных БПЛА.
- Явная оценка снижения динамической ошибки по тактам после начала маневра.
- Совместный подбор параметров IMM и нейросети генетическим алгоритмом.
- Прогноз начала маневра (если будет реализован).

## 3. Данные

**Реальные логи** - копия в `flight_logs/` (только чтение; исходник - папка
`Логи полетов для девушки новое\`).
- Из лога берутся время, GPS и высота: это истинная траектория. Остальные колонки
  (тип аппарата по имени файла, режим, углы, скорость) - только для разбиения и
  разбора результатов, во входы моделей не идут.
- Телеметрия EdgeTX/OpenTX, шаг 2 с (у T1 VTOL - 1 с).
- Аппараты: Dolphin, Z-84, T1 Ranger VTOL, S1100, Mini Talon, Skywalker X8
  («Черника»), Go Discover.
- После очистки на этапе 0: 23,5 ч самолётных полётов. Числа по выборкам - в
  `PROJECT_STATE.md` и `results/stage0/summary.txt`.
- Не используются:
  - `Sim-*` - симулятор, держим отдельно, в тест не идёт;
  - мультикоптеры F450 и Chimera7: данных почти нет.

**Синтетика** - кинематическая модель класса самолётных БПЛА, без моделей
конкретных аппаратов. Пределы скорости, разворота и вертикальной скорости
калибруются по совокупной статистике реальных логов. Синтетика - чистая
истина, шум добавляет только модель РЛС. Нужна для обучения (больше маневров) и для
контролируемого анализа (известные параметры маневра).

**Модель РЛС** (по умолчанию, по паспортам [51-54]):
- РЛС в наземной точке рядом с районом полёта;
- ошибки: по дальности σ = 5 м, по азимуту 0,75°, по углу места 1°;
- период обзора 2 с;
- вероятность обнаружения (`RADAR_PD`) заложена, по умолчанию 1,0, то есть без
  пропусков; пропуски - вариант C;
- РЛС для каждой трассы на 1-4 км от её центра, на 50 м ниже нижней точки.

**Разбиение.** Только целыми полётами:
- train / val / test - реальные полёты;
- синтетика - только в train;
- отдельный тест - тип БПЛА, которого не было в обучении.

## 4. Методы

**Базовые методы:**
- линейная экстраполяция (CV);
- фильтр Калмана (CV);
- IMM (модели CV и CT; CA исключена по результатам этапа 1, см. ниже);
- сквозные нейросети без IMM: GRU и Mamba по типу MambaMTT. Показывают,
  помогает ли IMM нейросети.

**Гибрид.** IMM прогнозирует на 1..H обзоров вперёд. Корректор получает окно из K
последних отметок и оценок IMM, вероятности моделей и невязки, а выдаёт поправки
к прогнозу IMM.

**Корректоры:** LSTM, GRU, Transformer (по типу PatchTST), Mamba.

**Подбор гиперпараметров:**
- Optuna с генетическим сэмплером NSGA-II;
- одинаковое число запусков на архитектуру;
- вместе с параметрами сети подбираются шумы и вероятности переходов IMM.

**Заложено, делается при наличии времени:**
- выход «вероятность начала маневра за k обзоров»;
- область неопределённости (строб);
- пропуски отметок (вариант C);
- схема «сеть переключает модели IMM» (вариант Б) с архитектурой-победителем.

## 5. Метрики

**Точность прогноза:**
- MAE, RMSE, ADE, FDE;
- R², считается по смещению от последней отметки;
- всё отдельно по горизонтам и типам участков.

**Динамическая ошибка** - кривая ошибки по тактам после начала маневра:
- пик;
- площадь под кривой за первые N тактов;
- число тактов до возврата к уровню прямолинейного полёта.

**Начало маневра:** точность, полнота, за сколько обзоров предупреждение.

**Ресурсы:** число параметров, время прогноза на шаг.

**Процесс выбора модели** (решения пользователя 27.10.2026). Основа - этапы 1-5, дальше
этапы 6-8:
1. **Основа.** Для каждого случая доплера (три) и каждого прогона (четыре) - 12 основ.
   Кандидаты: классические методы, IMM + корректор четырёх архитектур, сети без IMM,
   схемы A и Б. Генетический подбор в двух видах: гиперпараметры (этап 2) и архитектура
   (этап 4). Основа - лучший кандидат по val.
2. **Гипотезы по одной против основы.** Четыре обучаемые: вес ошибкам, три гипотезы
   прогноза, модульная схема, прогноз начала маневра. Подбор - только там, где
   гипотеза меняет вход или устройство сети (три гипотезы, модульная схема, начало
   маневра); вес ошибкам меняет лишь функцию потерь, параметры берутся с основы.
3. **Правило отбора:** гипотеза проходит, если на val разность ADE с основой
   отрицательна и её 95% интервал (бутстреп по полётам, на val) не содержит 0. По test
   не отбираем. Решение принимается **в каждой основе отдельно**: у разных случаев
   доплера и прогонов выжившие могут различаться.
4. **Сочетания.** Все сочетания выживших (2^k - 1, одиночные уже посчитаны). «Три
   гипотезы» и «модульная схема» **несовместимы** (обе меняют выход сети, это уже другая
   модель), их пара и содержащие её сочетания не строятся. Подбор в сочетаниях -
   генетический (NSGA-II, две цели: ADE val и время отклика), только там, где меняется
   вход или устройство сети.
5. **Ансамбль** - не гипотеза для перебора, а последний шаг: надевается на лучшее
   сочетание основы (или на саму основу, если никто не выжил).
6. **Оценка числа:** 12 основ, 48 одиночных обучений, 0-132 сочетаний (7 новых на основу
   при 4 выживших и исключённой паре вместо 11); ожидаемо 12-48.
7. **Что не берётся в сочетания:** шум РЛС и оракул (разложение ошибки, этап 9),
   доплер по телеметрии (третий случай, а не гипотеза), доплер в сочетаниях (случаи).
8. Для отбора нужны интервалы на val: в версии 1 они считались только на test.

Объём счёта: подбор в каждом из 4 прогонов и в трёх случаях - по опыту версии 1
порядка нескольких суток на домашнем ПК; точнее - после первых замеров.

### Этап 0. Каркас и данные (рабочий ПК) - выполнен 18.10.2026, 26 проверок PASS

Отличия реализации от первоначального плана:
- добавлена перепривязка времени GPS (`RISKS.md`, п. 1);
- скорость синтетики берётся из распределения логов, развороты - целыми
  маневрами логов (скорость, |w|, длительность);
- заданная |w| калибруется пробными генерациями через ту же цепочку измерения;
- GoDiscover включён (летающее крыло, подтверждено пользователем).

**Что делается:**
1. **Каркас:** `config.py`, общая настройка журнала (консоль + файл), seed, пути.
2. **Чтение логов.** Основа - парсер старого проекта, исправления описаны в
   `REFERENCES.md`:
   - отрезать наземные участки;
   - резать полёт на куски по паузам в записи;
   - фильтровать скачки по реальным пределам скорости;
   - локальная система ENU с началом в точке старта;
   - родной шаг без интерполяции;
   - метаданные для разбиения и анализа (не входы моделей): тип аппарата,
     real / sim, прошивка по режимам полёта.
3. **Разметка участков** по скорости разворота истины: прямая / вход в маневр /
   маневр / выход. Пороги - в `config.py`.
4. **Генератор.** Идеи сценариев взяты из старого проекта, модель новая:
   - кинематика самолётного БПЛА с ограничением крена, ускорения и вертикальной
