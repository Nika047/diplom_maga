## Принято

- **Направление** - вариант A: IMM + нейросетевой корректор, упор на сравнение
  LSTM / GRU / Transformer / Mamba и на снижение динамической ошибки при маневре.
- **Объект** - самолётные БПЛА. Модель РЛС с параметрами по умолчанию (`PLAN.md`,
  раздел 3).
- **Входы моделей** - только отметки РЛС и время. Тип аппарата и телеметрия -
  только для разбиения и анализа.
- **Генератор** пишется заново на кинематической модели класса самолётных БПЛА,
  без шума в истине. Ошибки старого - в `REFERENCES.md`.
- **Генетический подбор** - библиотека Optuna, сэмплер NSGA-II.
- **Задел на «если хватит времени»:** прогноз начала маневра, строб, пропуски
  отметок, вариант Б.
- **Журнал** - в консоль и в `log/`. Рисунки - в `results/stageN/`. Каждый этап
  заканчивается проверками PASS / FAIL.
