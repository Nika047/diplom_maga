## Принято

- **Направление** - IMM + нейросетевой корректор, сравнение LSTM / GRU / Transformer / Mamba, схемы встраивания,
  три случая доплера; итог - лучшая модель без доплера и с доплером (предложение: `nodop` и `dop_tele` - скорость
  по телеметрии честнее; выбор за пользователем после результатов).
- **Входы моделей** - только отметки РЛС и время (и радиальная скорость в случаях с доплером). Тип аппарата и
  телеметрия - только для разбиения, анализа и модели измерения доплера по телеметрии.
- **Истина логов** - GPS после очистки и перепривязки времени. Синтетика - без шума.
- **Процесс выбора модели** - основа (этапы 1-5) -> гипотезы по одной (этап 6) -> сочетания выживших (этап 7) ->
  ансамбль последним шагом (этап 8); отбор по val: интервал парной разности ADE с основой по полётам левее нуля,
  в каждой основе отдельно; шум РЛС и оракул - анализ итоговой модели, не гипотезы; «три гипотезы» и «модульная
  схема» несовместимы.
- **Генетический подбор** - Optuna, NSGA-II; цели: ADE val и время отклика сети (мс на обзор); подбор IMM и KF -
  одна цель.
- **Данные обучения везде** - реальные train + расширение (переразметка РЛС, отражение, растяжение по скорости) +
  синтетика; val и test не расширяются. Главный вариант данных для текста - merged (решение 26.10.2026).
- **IMM** - модели CV и CT (`config.py`, комментарий к `IMM_MODELS`). **Метрики** - по горизонтали; 3D - отдельно.
- **Результаты версии 1** (для сравнения и текста) - `home_results_archive/v1/`, `THESIS_NOTES.md`, `COMPARISON.md`;
  основные числа версии 1: IMM + GRU на `merged` test 41,1 м против 49,5 у подобранного IMM (-17%), с доплером и
  расширением 36,6 м; в текст как основные они не идут.
