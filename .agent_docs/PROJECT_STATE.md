## Принято

- **Направление** - вариант A: IMM + нейросетевой корректор, сравнение LSTM / GRU
  / Transformer / Mamba, снижение динамической ошибки при маневре.
- **Входы моделей** - только отметки РЛС и время. Тип аппарата и телеметрия -
  только для разбиения и анализа.
- **Истина логов** - GPS после очистки и перепривязки времени. Синтетика - без
  шума.
- **Генетический подбор** - Optuna, NSGA-II.
- **IMM** - модели CV и CT, CA исключена (`config.py`, комментарий к `IMM_MODELS`).
- **Метрики** - по горизонтали; 3D - отдельно.
- **Задел:** прогноз начала маневра, строб, пропуски отметок, вариант Б.
