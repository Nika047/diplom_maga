# Риски и слабые места

Подтверждённые - с причиной. Предположения помечены. Не чинить попутно: только
в рамках своего этапа.

## Данные

1. **Рассинхрон GPS и времени лога** (найдено на этапе 0).
   - Метки лога идут ровно через 2,00 с, а GPS обновляется со своим шагом.
     Смещения за шаг чередуются, например 28 / 49 / 25 / 48 м: корреляция соседних
     приращений скорости -0,75.
   - Решение - перепривязка времени по 3D-пути (`RETIME_*` в `config.py`). После
     неё корреляция -0,18.
   - Остаточная ошибка времени - доли секунды, то есть единицы метров вдоль
     траектории. Это погрешность самой истины.
2. **Выбросы GPS и высоты.** В логах ArduPilot высота до ±30 км. Решение -
   диапазон высоты и фильтр скачков. Итоги - в `results/stage0/summary.txt`.
3. **Паузы и «зависшая» телеметрия.** Около 10 тыс. повторов одной точки, около
   1,5 тыс. разрезов по паузам. Полёты делятся на 125 кусков.
4. **Шаг логов 2 с** (T1 VTOL - 1 с). РЛС с обновлением чаще 2 с без интерполяции
   не смоделировать - моделируется медленная обзорная РЛС. Ограничение работы.
5. **Перекос по аппаратам.** Dolphin - 16,2 из 20,1 ч самолётных полётов.
   Отложенный тип Z84 - всего 0,43 ч, 6 логов. Метрики приводить и по типам.
6. **GPS как истина.** Погрешность самой телеметрии - порядка метров плюс
   остаток рассинхрона (п. 1). Ошибки прогноза меньше этого уровня не
   интерпретировать.
7. **Мультикоптеров почти нет** (исключены). Выводы - только про самолётные БПЛА.
8. **GoDiscover (3,4 ч) исключён:** тип не подтверждён пользователем. По режимам
   ArduPlane похож на самолёт. Если подтвердится - добавить в `USED_AIRCRAFT`.

## Методы

9. **Синтетика против реальности.**
   - Скорость и |w| совпадают с логами по квантилям (сводка этапа 0).
   - Заданная |w| увеличена множителем около 1,85, чтобы совпала измеренная по
     2-секундным точкам. Пиковая заданная скорость разворота поэтому выше
     измеренной в логах; физический предел крена соблюдается.
   - Тест - только на реальных полётах.
10. **Mamba под Windows** (предположение): официальный `mamba-ssm` может не
    собраться. Тогда реализация на чистом PyTorch.
11. **Бюджет генетического подбора** на домашнем ПК неизвестен. Замерить время
    одного обучения до запуска подбора.
12. **Строб с гарантией (если будет).** Калибровка на других полётах, проверка
    покрытия отдельно на маневрах.
