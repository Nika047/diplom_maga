# Риски и слабые места

Подтверждённые - с причиной. Предположения помечены. Не чинить попутно: только
в рамках своего этапа.

## Данные

1. **Скачки GPS и высоты в логах.** Подсчёт 17.10.2026 по папке логов:
   - около 0,6% шагов со скоростью больше 100 м/с;
   - в логах ArduPilot (папка `Новая папка`) диапазон высоты - десятки километров.

   Без очистки один выброс испортит метрики.
2. **Паузы в записи.** Шаг лога местами 4-26 с, у `Sim-2026-01-14-113840` - 3541 с.
   Интерполяция через паузу рисует несуществующие прямые участки. Решение - резать
   полёт на куски.
3. **Шаг логов 2 с.** РЛС с обновлением чаще 2 с без интерполяции не смоделировать,
   поэтому моделируется медленная обзорная РЛС. Это ограничение работы.
4. **Перекос по аппаратам.** Dolphin занимает около 2/3 времени полёта (оценка
   17.10.2026). Метрики нужно приводить и по каждому типу.
5. **GPS как истина.** У самой телеметрии погрешность порядка метров. Ошибки
   прогноза меньше этого уровня интерпретировать нельзя.
6. **Мультикоптеров почти нет.** Выводы работы - только про самолётные БПЛА.

## Методы

7. **Обучение на синтетике.** Синтетика может не совпадать с реальными
   маневрами. Тест поэтому только на реальных полётах, а распределения синтетики
   сверяются с логами на этапе 0.
8. **Mamba под Windows** (предположение): официальный `mamba-ssm` может не
   собраться. Тогда нужна реализация на чистом PyTorch - медленнее, но для
   небольших данных достаточно.
9. **Бюджет генетического подбора** на домашнем ПК неизвестен. Замерить время
   одного обучения до запуска подбора.
10. **Строб с гарантией (если будет).** Гарантия конформного метода требует
    калибровки на других полётах и проверки покрытия отдельно на маневрах.
