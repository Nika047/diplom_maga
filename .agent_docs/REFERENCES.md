### Ошибки старого генератора

Это причина писать генератор заново, а не копировать:
1. **Барражирование:** подлёт заканчивается в центре круга, а кружение начинается
   на окружности - скачок позиции на 500-3000 м.
2. **Ложный маршрут:** точка смены курса записана дважды (нулевая скорость),
   разворот мгновенный.
3. **Уклонение:** время считается по прямому расстоянию, а не по длине сплайна -
   скорость выше заданной и плавает.
4. Шум GPS (σ = 10 м) и белый шум высоты (σ = 5 м) подмешаны в истину. У нас
   шум даёт только модель РЛС.
5. Нет ограничения скорости разворота по крену и меток участков. Высота не
   связана с горизонтальным движением.
6. Колонка `dt` хранит абсолютное время. Вместо журнала используется `print`.

## Источник данных: логи полётов

- **Копия в проекте:** `flight_logs/`, read-only. 150 CSV одним уровнем, побайтно
  совпадают с исходными (проверено `cmp` 18.10.2026). Код читает только её.
- **Исходник:** `C:\Users\1\Desktop\ГУАПчик\! мага\диплом\Логи полетов для девушки новое\`.
  В нём часть файлов лежит в подпапке `Новая папка/`, плюс `OpenTX2GPX.exe` (не
  запускать, не копировать). При копировании подпапка не сохранялась: прошивка
  определяется по кодам режимов `FM`.

- **Значимые колонки:** `Date`, `Time`, `GPS` («lat lon»), `Alt(m)`, `GSpd(kmh)`
  (км/ч), `Hdg(°)`, `VSpd(m/s)`, `Ptch(rad)`, `Roll(rad)`, `Yaw(rad)`, `FM`
  (режим полёта).
- **Прошивки:**
  - INAV - корень папки, режимы `ANGL`, `CRUZ`, `RTH`, `HOLD`, `AIR`;
  - ArduPilot - режимы `FBWA`, `CRUS`, `GUID`, `RTL`, `LOIT`, `ACRO`, `TKOF`.
    Звёздочка в конце - вариант записи режима.
- **Типы аппаратов** (со слов пользователя):

| Префикс файла | Аппарат |
|---|---|
| `Z84` | Z-84, летающее крыло, размах около 840 мм |
| `T1 VTOL` | T1 Ranger VTOL, самолётный VTOL-гибрид (есть режимы зависания) |
| `S1100` | S1100, крупная самолётная платформа |
| `Mini Talon` | Mini Talon |
| `Dolphin` | Dolphin, самолётная компоновка |
| `Chernika` | Skywalker X8, крупное летающее крыло |
| `Sim` | симулятор, в тест не идёт |
| `F450`, `Chimera7` | мультикоптеры, не используются |
| `GoDiscover` | тип не подтверждён |

- Тип аппарата и режим - только для разбиения и анализа, не входы моделей
  (`AGENTS.md`).
