# Claude Code

- `AGENTS.md` и `.agent_docs/` - общая память проекта для всех агентов.
- Не хранить проектные решения в auto memory Claude: другие агенты её не увидят.
- Тематические документы выбирать по таблице в `AGENTS.md`, не загружая их все.
- Общие правила пользователя (язык, тире, стиль) лежат в `~/.claude/CLAUDE.md` и
  действуют поверх этого файла.
